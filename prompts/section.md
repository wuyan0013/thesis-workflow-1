# 章节内容生成提示词（严格版 v2.0）

## 任务描述
根据论文大纲和上下文，生成指定章节的完整内容。

## 输入信息
- 章节标题：{section_title}
- 章节要求：{section_requirements}
- 上下文摘要：{context}
- 目标字数：{word_count}

## 写作规范（必须严格遵守）

### 1. 内容来源要求
- 所有观点必须基于可查证的学术资料（期刊论文、政府报告、统计数据）
- 本章节必须整合至少3-5个不同来源的观点
- 禁止凭空捏造任何数据、案例或结论
- 重要论点需有理论或实证支撑

### 2. 人类化写作要求（核心反AI检测措施）

#### 句式变化（必须混合）
- 使用短句强调重点（如"这一问题值得关注。"）
- 使用中长句进行分析（25-40字的复杂论述）
- 使用复合句连接逻辑（"虽然...但是...""由于...因此..."）
- 避免句式单一！每3-4句必须有明显的句式变化

#### 自然过渡（必须频繁使用）
- 递进："此外""与此同时""进一步分析可以发现""更为重要的是"
- 转折："然而""不过""从另一个角度看""值得注意的是"
- 因果："因此""基于此""正因如此""这直接导致了"
- 总结："综合来看""从整体分析""基于以上讨论"

#### 叙述流（禁止机械分点）
- 禁止"首先、其次、再次、最后"结构
- 禁止"第一、第二、第三"罗列
- 将要点整合成连贯的段落叙述
- 使用"在这一背景下...与此同时...值得关注的是..."的叙述方式

#### 学术化个人解读（适度添加）
- "结合实际情况分析，这一现象反映了..."
- "从目前的发展趋势来看，可以初步认为..."
- "这一变化在某种程度上说明了..."

#### 学术谦虚表述（必须包含2-3处）
- "基于现有资料的分析"
- "从目前可获得的信息来看"
- "初步研究表明"

### 3. 绝对禁止的表述
- "笔者认为""依笔者之见""笔者以为"（全部禁止！）
- "填补空白""弥补空白"（禁止自我吹捧）
- "首先...其次...再次..."（禁止机械结构）
- 每段开头都用"综上所述"（禁止滥用）

### 4. 格式要求
- 直接输出正文内容，不要重复章节标题
- 可使用"## "表示二级小节标题
- 段落之间用空行分隔
- 不使用加粗、斜体等格式
- 不使用编号（如"一、""（一）"）

## 输出示例

```
## 相关概念界定

在当前学术研究中，关于这一概念的界定存在多种观点。从较为广泛接受的定义来看，学者张某（2020）将其概括为一种特定的社会现象，强调其在实践层面的表现特征。与此同时，李某（2021）的研究则从另一个角度进行了补充，指出这一概念还应包含制度层面的内涵。

值得注意的是，不同研究者对于概念边界的划定存在一定差异。从目前可获得的资料来看，这种差异主要源于研究视角的不同。基于现有研究的梳理，可以初步认为该概念具有多维度的特征，既包含显性的表现形式，也涉及深层的运作机制。这一认识对于后续研究具有重要的参考价值。

## 相关概念辨析

这一概念与相近概念之间的关系，同样是学界关注的焦点。从实践来看，两者虽然在某些方面存在交叉，但其核心内涵却有着明显的区别。综合多位学者的观点，这种区别主要体现在适用范围和作用机制两个层面。

在适用范围上，前者更侧重于宏观层面的分析，而后者则关注微观个体的行为特征。基于这一认识，在实际研究中需要注意概念使用的准确性，避免混淆。从目前的发展趋势来看，厘清这些概念之间的边界，对于推进该领域的深入研究具有重要意义。
```

注意：示例中展示了人类化写作的核心特征——句式多样、自然过渡、叙述流畅、无机械分点。

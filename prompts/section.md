# 章节内容生成提示词

## 任务描述
根据论文大纲和上下文，生成指定章节的完整内容。

## 输入信息
- 章节标题：{section_title}
- 章节要求：{section_requirements}
- 上下文摘要：{context}
- 目标字数：{word_count}

## 写作要求

### 语言风格
1. 使用学术化、正式的语言
2. 避免口语化表达
3. 适当使用专业术语
4. 保持客观、中立的叙述角度

### 结构要求
1. 开头需有承上启下的过渡句
2. 段落之间逻辑衔接自然
3. 每段围绕一个中心思想展开
4. 结尾需总结本节要点，引出下一节

### 内容要求
1. 论点明确，论据充分
2. 理论联系实际
3. 适当引用文献支撑观点
4. 避免空泛的描述

### 格式要求
1. 使用Markdown格式
2. 合理使用二级、三级标题
3. 重要概念可加粗
4. 列举时使用列表格式

3. **特征三**：具体说明

综上所述，本文采用某某（2018）的定义，将XX界定为......
